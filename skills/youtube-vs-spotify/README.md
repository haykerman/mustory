# YouTube vs Spotify

A Claude skill that lines up your YouTube watch history with your Spotify listening history and turns the difference into one page: which app does the work each year, when you use each, which app finds artists first, which artists live on one app, and the songs you play everywhere.

## Install (Claude Code)

1. Unzip into `~/.claude/skills/`, so you have `~/.claude/skills/youtube-vs-spotify/SKILL.md`.
2. Have both exports ready: a Google Takeout YouTube history zip and Spotify's `my_spotify_data.zip` (Extended streaming history is best).
3. Start Claude Code and say: **"Compare my YouTube and Spotify."**

Everything stays on your computer. Needs Python 3.9+. Pairs well with the youtube-wrapped and spotify-wrapped skills.
