# YouTube Wrapped

A Claude skill that turns your YouTube watch history into a Spotify Wrapped–style page: your eras, obsessions, forgotten favorites, night-owl hours, rabbit holes and a personality read.

## Install (Claude Code)

1. Unzip this folder into `~/.claude/skills/`, so you have `~/.claude/skills/youtube-wrapped/SKILL.md`.
2. Start Claude Code (terminal, desktop app or IDE) and say: **"Make my YouTube Wrapped."**

Claude walks you through the Google Takeout export (about 10 minutes, plus Google's wait), then builds the page. Your history stays on your computer. It needs Python 3.9 or newer, which macOS and most Linux systems already have.
