# Spotify Wrapped (any time of year)

A Claude skill that turns your Spotify data export into a Wrapped-style page that goes further than Spotify's: lifetime hours, eras, loops, your skip button, autopilot vs songs you picked, focus music, devices, travel, discovery and a personality read.

## Install (Claude Code)

1. Unzip into `~/.claude/skills/`, so you have `~/.claude/skills/spotify-wrapped/SKILL.md`.
2. Start Claude Code and say: **"Make my Spotify Wrapped."**

Claude explains how to request your **Extended streaming history** from Spotify (it can take a few days), then builds the page. Your data stays on your computer. Needs Python 3.9+.
